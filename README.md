# 공부방 출석부 (출결 + 학부모 문자 알림)

원장님이 휴대폰 웹 화면에서 **출석**을 누르면 학부모님께 등원 문자가 가고,
수업 메모를 써두면 **피드백 보내기** 한 번으로 학부모님들께 한꺼번에 보내지는 출석부.

- 학생·학부모: 설치할 것 없음 (학부모는 일반 문자로 받음)
- 원장님: 인터넷 주소 하나 (홈 화면에 추가하면 앱처럼 사용)

## 화면

| 화면 | 하는 일 |
|---|---|
| 출석부 | (설정에서 등원 카톡을 켠 경우) 출석 시 학부모님께 등원 카톡. 그날 요일에 수업 있는 반 학생만 자동으로 표시 (체크 안 한 학생 → 수업 이른 순으로 위에. 누르는 동안은 줄이 안 움직이고, 다시 들어오면 정리됨), 출석 시 등원 문자, 수업 메모, 피드백 일괄 발송 |
| 공지 | 받을 학생을 전체·반·직접 체크로 골라 학부모님마다 "새 공지가 있어요 + 링크" 카톡 (형제는 한 번만, 이름은 "김민수·김민지"). 링크(`/n/…`)를 열면 로그인 없이 공지 전체. 보낸 공지 기록 |
| 월별 | 학생별 월 출석·결석 횟수 + 그달 교습비 납부 여부·금액, **미납 학생에게 원비 안내 보내기** (학생을 누르면 납부 기록 입력: 날짜·교습기간·과목·교습비·기타경비·결제수단·메모, 선납 가능), 문자 사용량 |
| 학생·반 | 반 만들기(이름·요일·시각), 학생 추가·수정(생년월일 선택)·반 배정(여러 반 가능), **명단 붙여넣기**로 여러 명 한 번에 추가(한 줄에 이름·학년·학부모 번호, 칸 순서 자유, 엑셀 복사 가능, 미리보기 후 저장, 이미 있는 학생은 건너뜀), 그만둔 학생 숨기기 |
| 설정 | 이용권(요금제·남은 카톡 통수) 바로가기, **출석 체크하면 학부모님께 카톡 보내기** 켜기/끄기 (새 공부방은 꺼짐, 끄면 출석은 기록만), 학원 이름, 개인과외교습자 신고번호, 등원 문자(끝 문장·덧붙일 말)·피드백 문자(첫 줄·마지막 인사) 빈칸 채우기 + 미리보기, 로그아웃 |
| 마이페이지 (`/me`) | PC 는 사이드바 맨 아래 공부방 이름·아이디, 휴대폰은 설정 맨 위. 원장님 연락처 수정, 비밀번호 변경(지금 비밀번호 확인), 요금제·이용 기간·남은 카톡, 결제 내역, 로그아웃, **탈퇴** |
| 영수증 원부 | 월별 화면 교습비 칸 → 분기 고르기 → 교습비등 영수증 원부 A4 인쇄 (법정 장부, 5년 보관) |

원장님마다 반 구성·문구가 달라도 코드는 그대로 — 전부 원장님이 화면에서 설정한다.

## 문자 규칙 (중복·실수 방지)

- 등원 문자는 **오늘 날짜 + 출석**일 때 학생당 하루 **한 번만** 나감. 여러 번 눌러도, 결석→출석으로 바꿔도, 체크를 지웠다 다시 눌러도 다시 안 나감
- 출석·결석·메모를 바꾸면 화면 아래 5초간 **되돌리기** 알림. 이미 나간 등원 문자는 되돌려도 취소되지 않음 (알림에 안내)
- 지난 날짜의 출결을 고치면 기록만 바뀌고 문자는 안 나감
- 결석은 문자 없이 기록만
- 피드백은 버튼을 눌러야 나감 (두 번 확인). 이미 보낸 메모는 고칠 수 없음
- 발송 실패하면 화면에 표시되고, 다시 보내기 가능
- 나간 문자는 전부 `message_logs` 테이블에 남음
- 출석부 위에 **보내지 못한 문자 N건 · 다시 보내기** (일주일 안, 등원 문자는 오늘 것만). 이미 나간 건 다시 안 보냄
- 솔라피 잔액(잔액+포인트)이 `SOLAPI_LOW_BALANCE`(기본 5,000원) 밑이면 출석부 위에 경고. 테스트 모드에서는 "테스트 모드" 표시만

## 개인정보

- `/privacy` 개인정보 처리방침 (로그인 없이 열림). `/privacy?a=공부방id` 로 열면 그 공부방 이름·연락처가 들어감
- 학생을 추가할 때 "학부모님께 개인정보 수집·문자 수신 동의를 받았어요"를 체크해야 저장됨 (체크 시각은 `students.consent_at`)
- 설정 화면에서 학부모님께 보낼 동의 안내 문구(처리방침 링크 포함)를 복사할 수 있음
- 처리방침 문구(보관 기간 등)는 `src/app/privacy/page.tsx` 에서 고침 — 실제 운영 전에 한 번 검토 권장

## 내 컴퓨터에서 실행

준비물: Node.js 20 이상, PostgreSQL 주소 (무료: [Neon](https://neon.tech) 가입 → 프로젝트 만들기 → Connection string 복사)

```bash
npm install
cp .env.example .env      # 윈도우: copy .env.example .env
# .env 열어서 DATABASE_URL, SESSION_SECRET, SEED_PASSWORD 채우기
npm run db:push           # DB 테이블 만들기
npm run seed              # 원장님 계정 만들기 (+ 예시 반 5개·학생 8명)
npm run seed:reset        # 예시 데이터를 지우고 다시 넣기 (테스트용)
npm run dev               # http://localhost:3000
```

솔라피 키를 비워두면 **테스트 모드**: 문자는 안 나가고 화면 위에 노란 띠가 뜨고, 기록만 남음.

## 실제 문자 보내기 (솔라피)

1. [solapi.com](https://solapi.com) 가입 → 충전
2. **발신번호 등록**: 원장님 휴대폰 번호를 등록 (원장님 본인 인증 필요 — 전기통신사업법상 등록된 번호로만 발송 가능)
3. 콘솔에서 API Key / API Secret 발급
4. `.env` 에 `SOLAPI_API_KEY`, `SOLAPI_API_SECRET` 넣고, `SEED_SENDER_PHONE` 에 등록한 번호 넣고 `npm run seed` 다시 실행
5. 본인 번호를 학부모 번호로 넣은 테스트 학생으로 먼저 확인

한글 약 45자(90바이트)를 넘으면 장문(LMS)으로 나가서 건당 요금이 더 비쌈. 피드백은 대부분 장문.

## 카카오 알림톡 (문자보다 싸게)

설정을 안 하면 지금처럼 전부 문자로 나간다. 아래를 마치면 **등원 알림 · 수업 피드백 · 원비 안내 · 수업 일정 안내 · 학부모 동의 요청**이 알림톡으로 바뀌고,
알림톡이 실패하면(카톡 없는 학부모 등) 솔라피가 같은 내용을 발신번호로 문자 대체 발송한다.
피드백은 메모 전체가 카톡에 바로 보인다(줄바꿈 그대로). 카톡 한 통은 1,000자까지라 넘으면 메모를 줄이고 끝에 "…(전체 내용은 아래 버튼)" → [피드백 전체 보기] 버튼이 `/f/…` 를 연다 (`APP_URL` 필요).
템플릿 ID 가 없는 종류는 아래 템플릿과 같은 글이 문자로 나간다 (피드백은 줄였을 때만 끝에 `/f/…` 링크).

공지는 두 종류다. **수업 일정 안내**(휴원·보강·수업 시간 변경)는 알림톡, **기타 공지**는 자유롭게 써서 문자(장문)로만 보낸다.
기타 공지는 문자 원가만큼 통수를 뺀다 (`src/lib/pricing.ts` `SMS_UNITS`: 단문 2통 · 장문 4통, 알림톡 13원 = 1통 기준 올림).
예전 공지사항 템플릿(`SOLAPI_TEMPLATE_NOTICE`)은 반려돼서 안 쓴다. 예전 공지 링크(`/n/…`)는 계속 열린다.

`#{호칭}` 은 학생별로 저장된 호칭이 없어서 "김하늘 학생 학부모님"(형제는 "김민수·김민지 학생 학부모님")으로 들어간다.

| 종류 | 알림톡 | 비고 |
|---|---|---|
| 등원 알림 | 학원·이름·시각 | 출석을 누르면 (설정에서 등원 카톡을 켠 공부방만) |
| 수업 피드백 | 학원·호칭·이름·날짜·피드백 + 버튼(코드) | 출석부 → 피드백 보내기. 메모가 카톡에 바로 |
| 원비 안내 | 학원·이름·○월분·금액·납부일 | 월별 화면 → 미납 → 원비 안내 보내기 |
| 수업 일정 안내 | 학원·호칭·이름·종류·날짜·내용 | 공지 → 수업 일정 안내. 종류는 휴원/보강/수업 시간 변경 버튼, 날짜·내용은 원장님이 입력. 형제는 한 통 |
| (기타 공지) | 알림톡 없음 → 문자 | 공지 → 기타 공지. 광고(할인·모집·이벤트)는 보낼 수 없음 |
| 학부모 동의 요청 | 학원·이름·링크 | 학생·반 → 동의 요청 보내기. 링크(`/c/…`)에서 동의·거부 |

1. 카카오톡 채널 만들기 → 비즈니스 인증 (한 번만. 여러 공부방이 이 채널 하나로 받게 할 수 있는지 솔라피에 먼저 문의)
2. 솔라피 콘솔 → 카카오 → 채널 연동 → 나온 `PF…` ID 를 `SOLAPI_KAKAO_PF_ID` 에
3. 솔라피 콘솔 → 알림톡 템플릿 등록. 아래 5개를 **글자 하나 바꾸지 않고** 등록 (`src/lib/alimtalk.ts` 와 같아야 함)
4. 승인되면 템플릿 ID(`KA…`)를 각각 `SOLAPI_TEMPLATE_ATTENDANCE` / `SOLAPI_TEMPLATE_FEEDBACK` / `SOLAPI_TEMPLATE_PAYMENT` / `SOLAPI_TEMPLATE_SCHEDULE` / `SOLAPI_TEMPLATE_CONSENT` 에 (로컬 `.env` 와 Vercel 둘 다)
5. `APP_URL` 에 배포 주소 (전체 보기·동의 링크용). Vercel 환경변수에도 똑같이 넣고 다시 배포

등원 알림 (`SOLAPI_TEMPLATE_ATTENDANCE`)
```
[#{학원}] 등원 알림

#{이름} 학생이 #{시각}에 등원했습니다.
```

수업 피드백 (`SOLAPI_TEMPLATE_FEEDBACK`) — 버튼(웹링크) **피드백 전체 보기** → `https://gongbubang-tau.vercel.app/f/#{코드}` (모바일·PC 같게, 외부 브라우저 열기 끔)
```
[#{학원}] 수업 피드백 안내

#{호칭}, 안녕하세요.
#{이름} 학생의 #{날짜} 수업 피드백을 보내드립니다.

■ 선생님 피드백
#{피드백}

※ #{학원}에서 수업을 듣는 학생의 학부모님께 수업 후 보내드리는 학습 안내입니다.
```

교습비 납부 안내 (`SOLAPI_TEMPLATE_PAYMENT`)
```
[#{학원}] 교습비 납부 안내

#{이름} 학생의 #{월} 교습비 납부 안내드립니다.

교습비: #{금액}
납부일: #{납부일}

이미 납부하셨다면 이 안내는 넘기셔도 됩니다.
```

수업 일정 안내 (`SOLAPI_TEMPLATE_SCHEDULE`)
```
[#{학원}] 수업 일정 안내

#{호칭}, 안녕하세요.
#{이름} 학생의 수업 일정 변경을 안내드립니다.

■ 안내 종류 : #{종류}
■ 해당 날짜 : #{날짜}
■ 변경 내용 : #{내용}

※ #{학원}에서 수업을 듣는 학생의 학부모님께 보내드리는 수업 일정 안내입니다.
```

학부모 동의 요청 (`SOLAPI_TEMPLATE_CONSENT`)
```
[#{학원}] #{이름} 학부모님, 안녕하세요. 출결·공지 안내를 카카오톡으로 보내드리려고 합니다. 아래 링크에서 내용을 확인하고 동의해 주세요.
#{링크}
```

템플릿 하나만 승인돼도 그 종류만 알림톡으로 바뀐다. 문구를 바꾸려면 `src/lib/alimtalk.ts` 를 고치고 카카오에 다시 심사받는다.

## 원비 안내 (미납)

월별 화면에 그달 납부 기록이 없는 학생이 "미납 N명"으로 모인다. 눌러서 학생을 고르고 **원비 안내 보내기** (두 번 확인).
결제는 원장님이 지금처럼 결제선생·계좌이체로 받고, 받으면 학생을 눌러 납부 기록을 남긴다. 이미 안내한 학생은 "10/31 안내함"으로 표시되고 기본 체크가 꺼진다.

## 회원가입 · 요금제

원장님이 `/signup` 에서 직접 가입 → 바로 로그인, **무료 체험 14일** 시작 (`TRIAL_DAYS`). 충전금은 없고, 카톡·문자는 요금제에 든 통수만큼 보낸다.

| 요금제 | 가격 | 카톡·문자 |
|---|---|---|
| 무료 체험 (`TRIAL`) | 14일 무료 | 30통 |
| 기본 (`BASIC`) | 월 5,900원 | 150통 |
| 넉넉 (`PLUS`) | 월 9,900원 | 400통 |

| | 내용 |
|---|---|
| 통수 세기 | 결제일(없으면 가입일, `period_start`)부터 한 달씩 끊어서 새로 셈. 알림톡·문자 모두 1건 = 1통 (기타 공지 문자만 단문 2통·장문 4통). 보내기 직전에 한 번에 확보(`reserveQuota`)하고 실패·접수 거절은 돌려놓음. 테스트 모드(`TEST` 기록)도 셈 |
| 다 쓰면 | 한 통도 안 나가고 "보내지 못한 문자"로 남음. 출석은 기록됨. 모든 화면 맨 위에 "이번 달 카톡을 다 썼어요 [9,900원으로 올리기]" → 결제하면 바로 다시 보내기 가능 |
| 결제 | 토스페이먼츠 결제창(카드). 자동결제 아님. 결제하면 그 요금제로 바뀌고, 오늘부터 통수를 새로 세고, 남은 기간 뒤에 한 달이 이어 붙음. 주문을 먼저 DB 에 만들고(금액은 서버가 정함) → `/billing/success` 에서 서버가 승인 API 호출 → 승인돼야만 반영 |
| 기간 끝나면 | 보기·영수증 원부 인쇄는 됨. 출석·발송·학생 추가 같은 바꾸는 동작은 결제 화면으로 보냄 (`requireActiveAcademy`) |
| 화면 | 설정 › 이용권 (`/billing`): 남은 통수 + 요금제 2개. 체험 3일 이하·기간 끝남·통수 10% 이하/다 씀이면 모든 화면 맨 위에 한 줄 |
| 예전 데이터 | `plan = PAID` 는 기본으로 봄. `credit_won`·`credit_ledger` 는 안 쓰고 기록만 남김. 예전 충전금 주문(`CREDIT`)은 승인하지 않음 |
| 탈퇴 | 비밀번호 확인 → 학생·학부모 번호·반·출결·메모·교습비·공지·메시지 기록 삭제. 결제 기록(`orders`, 예전 `credit_ledger`)은 5년 보관하려고 공부방 줄은 남기되 이름·아이디·비밀번호·연락처를 비우고 `deleted_at` 기록. 원장님 연락처는 HMAC(`trial_phone_hash`)만 남겨서 같은 번호로 다시 가입하면 무료 체험 없이 결제 화면으로 (⚠ `SESSION_SECRET` 을 바꾸면 이 비교가 안 맞음). 5년 지난 기록을 지우는 작업은 아직 없음 |
| 약관 | `/terms` 이용약관·환불 규정 (사업자 정보는 `BUSINESS_*`). ⚠ 초안 — 운영 전 검토 |

솔라피 잔액은 원장님 화면에 안 보임 (두나가 솔라피 콘솔에서 관리). 전체 공부방 통수를 다 써도 모자라지 않게 넉넉히 넣어 둔다.

### 두나용 관리 명령

```bash
npm run admin -- list                      # 공부방 목록 (요금제·이용 기간·이번 달 카톡 남은/전체)
npm run admin -- plan hyunsaem PLUS        # 요금제 바꾸기 (BASIC / PLUS / TRIAL). 기간·쓴 통수는 그대로
npm run admin -- extend hyunsaem 1         # 이용 기간 1개월 늘리기 (남은 기간 끝에서, 끝났으면 오늘부터)
npm run admin -- days hyunsaem 30          # 오늘부터 30일까지로 정하기
npm run admin -- unlimited demo            # 데모 계정 기한 없음
npm run admin -- notify hyunsaem off       # 등원 카톡 끄기 (on 으로 다시 켬, 설정 화면 스위치와 같음)
```

`npm run seed` 로 만든 계정은 기한 없음(`service_until` 비어 있음). 원장님께 드리는 계정은 `days` 로 기간을 정한다.

### 토스페이먼츠 준비

1. 토스페이먼츠 가입(사업자) → 개발자센터 **API 개별 연동 키** (결제위젯 키 아님)
2. 테스트 키로 먼저: `.env.example` 의 공개 테스트 키를 넣으면 실제 돈 없이 결제 흐름 확인 가능
3. 실제 결제는 토스 계약·심사 후 live 키로 교체. 심사 때 사이트의 이용약관·환불 규정·사업자 정보를 봄 (`/terms`)

### 딜러사 메모

솔라피보다 싼 알림톡 딜러사(비즈고 7.12원 등)는 **API 호출 IP 를 미리 등록**해야 하는데 Vercel 은 IP 가 계속 바뀜 (고정 IP 는 Pro + 월 $100).
공부방이 늘면 고정 IP 작은 서버를 두고 교체 검토. 그 전까지 솔라피 유지, 원장님 건당 가격은 `PRICE_*` 로 조정.

## 배포 (Vercel)

1. GitHub에 올리기 (`.env` 는 자동으로 제외됨)
2. Vercel → New Project → 저장소 선택
3. Environment Variables 에 `.env` 의 값 넣기 (`DATABASE_URL`, `SESSION_SECRET`, `SOLAPI_API_KEY`, `SOLAPI_API_SECRET`)
4. 배포 후 원장님 휴대폰에서 주소 열기 → 공유 → **홈 화면에 추가**

## 원장님 추가 (두 번째 공부방부터)

모든 테이블에 `academy_id` 가 있어서 같은 배포에 계정만 추가하면 됨.
`.env` 의 `SEED_ACADEMY_NAME`, `SEED_LOGIN_ID`, `SEED_PASSWORD`, `SEED_SENDER_PHONE` 을 바꾸고 `SEED_SAMPLE_STUDENTS="false"` 로 `npm run seed`.
(같은 솔라피 계정에 원장님별 발신번호를 각각 등록해야 함)
